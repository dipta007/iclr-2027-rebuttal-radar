    Credit. This site is built on iclr-2027-scores by shiqiangw, who made the original ICLR 2027 Scores page, the data pipeline, and the first snapshot. The rebuttal sections were added in this fork.

    What is counted. Only official reviews and their overall rating. Withdrawn and desk-rejected papers are not listed. The page shows paper titles, numeric scores, and OpenReview links only. Visits are counted with Cloudflare Web Analytics, which uses no cookies. The paper you look up is not part of that count.

    Limits. A changed score is found by comparing each paper's sorted scores, so two opposite changes on one paper can hide each other. Past-year rates describe what happened to similar papers. They are not a prediction for any paper. Data comes from the OpenReview API and updates every 12 hours. Past-year numbers are built from the public data of Paper Copilot.
